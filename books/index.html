Want a better voice? Add one on your device
  • iPhone and iPad: Settings → Accessibility → Spoken Content → Voices → English. Download an Enhanced or Premium voice, then reload this page.
  • Mac: System Settings → Accessibility → Spoken Content → System Voice → Manage Voices.
  • Android: Settings → Accessibility (or General management) → Text-to-speech → Speech Services by Google → install voice data. Chrome works best.
  • Windows: Settings → Time & language → Speech → Manage voices → Add voices. Microsoft Edge has the most natural voices.

The voices come from your own phone or computer, so the list is different on every device.
